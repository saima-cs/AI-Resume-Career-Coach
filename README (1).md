
# AI Resume & Career Coach 🤖📄💼

An AI-powered career assistant built with Python, Streamlit, Groq API, and pypdf.

## Features

- 📄 Resume PDF upload and text extraction
- 🤖 AI resume analysis
- 📊 Resume and ATS scoring
- ✍️ AI resume section improvement
- 💼 Career match analysis
- 🧠 Skill gap analysis
- 📚 Personalized career roadmap
- 🚀 Portfolio project recommendations
- 🎤 Interview preparation and feedback
- 📊 Career readiness dashboard

## Tech Stack

- Python
- Streamlit
- Groq API
- pypdf
- GitHub
- Streamlit Community Cloud

## Architecture

User → Streamlit → Resume Parser → Groq AI → Career Analysis → Dashboard
